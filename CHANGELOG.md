# Changelog

## 1.0.0 - 2026-08-09

- Release the first limited Windows CPU reference terrain addon for Godot 4.7.
- Freeze `WtTerrainWorld` API version 2, four runtime profiles, generation-aware
  readiness, bounded viewer/query behavior, native edit persistence, targeted
  collision residency, editor authoring/inspection, and repro export.
- Pin `world-transvoxel` revision
  `f4abd7ab4f921f98aba4ee45b4453af0bae53cd8` with no terrain fallback.
- Add deterministic package, release-matrix, retained long-run, and bounded
  production-wrapper qualification evidence for TQP-55 through TQP-57.
