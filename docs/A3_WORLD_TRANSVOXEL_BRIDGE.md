# A3 World Transvoxel Bridge

Status: complete.

Validation markers:

```text

WT_TERRAIN_A3_GODOT_BRIDGE_PASS version=... backend_id=... license=MIT config_schema=... implementation=bridge_only
WT_TERRAIN_A3_BRIDGE_PASS engines=2 report=artifacts/a3_bridge_smoke/a3_bridge_smoke_report.json
```

A3 proves the terrain addon can detect and talk to the official
`world-transvoxel` Godot API without vendoring `world-transvoxel`, copying
`world-transvoxel-sandbox`, or copying MIT Transvoxel topology data into this
repository.

## Bridge boundary

`addons/world_transvoxel_terrain/runtime/wt_world_transvoxel_bridge.gd` is a
small adapter around Godot `ClassDB`.

It checks:

- `WorldTransvoxelTerrain` exists;
- `WorldTransvoxelConfig` exists;
- identity methods are callable;
- the official MIT backend reports available;
- default `WorldTransvoxelConfig` is valid;
- runtime metrics method exists.

It does not start a world, stream chunks, build terrain, edit terrain, or process
storage. Those are A4 responsibilities.

## Temporary fixture

`tools/a3_bridge_smoke.py` creates a temporary ignored Godot fixture under:

```text
artifacts/a3_bridge_smoke/project
```

The fixture copies:

- this repo's `addons/world_transvoxel_terrain`;
- a minimal runtime subset of sibling `world-transvoxel/addons/world_transvoxel`;
- `tests/a3_bridge_smoke.gd`;
- a generated fixture `project.godot`.

The copied dependency lives only under ignored `artifacts/`. No
`addons/world_transvoxel/` path is committed to this repository.

## GDScript boundary

The added GDScript is bridge/scaffolding only:

- dependency and class detection;
- backend identity and config validity queries;
- headless smoke test.

It does not own generation, meshing, streaming policy, edit recovery, persistent
storage processing, or compute-heavy validation.

## Exit criteria

A3 is complete when:

- `python tools/validate_terrain_skeleton.py` passes;
- `python tools/validate_a1_contract.py` passes;
- `python tools/validate_a2_smoke.py` passes;
- `python tools/validate_a3_bridge.py` passes;
- `python tools/a3_bridge_smoke.py` passes on discovered local Godot engines;
- A3 `.gd.uid` files generated by Godot import are committed;
- no `addons/world_transvoxel/`, MIT Transvoxel source, or sandbox
  implementation is committed.

Next valid action is A4: terrain profile, edit, storage, and recovery
implementation through the bridge.
