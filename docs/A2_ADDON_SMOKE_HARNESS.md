# A2 Addon-Local Smoke Harness

Status: complete.

Validation markers:

```text
WT_TERRAIN_A2_CONTRACT_PASS next=a3_world_transvoxel_bridge implementation=smoke_only
WT_TERRAIN_A2_GODOT_SMOKE_PASS dependency_installed=false profile=2048x64 implementation=placeholder_contract_only
WT_TERRAIN_A2_SMOKE_PASS engines=2 report=artifacts/a2_addon_smoke/a2_addon_smoke_report.json
```

A2 proves local addon loadability and dependency detection. It does not implement
terrain generation, meshing, streaming, edit recovery, storage, water, planets,
compute acceleration, or game validation.

## Added smoke assets

- `addons/world_transvoxel_terrain/api/wt_terrain_dependency_status.gd`
  detects whether `res://addons/world_transvoxel/plugin.cfg` exists and reports
  a clear status dictionary.
- `addons/world_transvoxel_terrain/api/wt_terrain_profile.gd` defines the
  placeholder 2048 x 2048 x 64 terrain profile resource.
- `addons/world_transvoxel_terrain/generation/wt_terrain_generation_profile.gd`
  defines placeholder generation-profile metadata, including volumetric
  underground support.
- `addons/world_transvoxel_terrain/runtime/wt_terrain_world.gd` defines the
  placeholder terrain-world node and exposes dependency/status summaries.
- `tests/a2_addon_smoke.gd` loads the plugin manifest and placeholder scripts in
  Godot headless mode.
- `tools/a2_addon_smoke.py` discovers local Godot engines, imports the project,
  runs the smoke script, and writes an ignored artifact report.
- `tools/validate_a2_smoke.py` validates the A2 contract and rejects vendored
  `world-transvoxel` or MIT Transvoxel source paths.
- Godot-generated `.gd.uid` files for the A2 scripts are tracked so script
  resource identity is not left as uncommitted import metadata.

## Dependency boundary

A2 intentionally supports missing-dependency mode. This repository must prove it
can detect `world-transvoxel` without vendoring it. The A3 bridge is the first
milestone allowed to require the actual backend API.

## GDScript boundary

The GDScript added by A2 is scaffolding only:

- editor plugin status reporting;
- dependency status reporting;
- placeholder Resource/Node names;
- headless smoke-test harness.

It does not perform terrain generation, meshing, streaming policy, persistent
storage processing, edit recovery, or compute-heavy validation.

## Exit criteria

A2 is complete when:

- `python tools/validate_terrain_skeleton.py` passes;
- `python tools/validate_a1_contract.py` passes;
- `python tools/validate_a2_smoke.py` passes;
- `python tools/a2_addon_smoke.py` passes on discovered local Godot engines;
- A2 `.gd.uid` files generated by Godot import are committed;
- no `addons/world_transvoxel/` dependency is vendored into this repository.

Next valid action is A3: define and test the `world-transvoxel` bridge boundary.
